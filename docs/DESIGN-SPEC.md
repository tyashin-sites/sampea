# Design spec — Sampéa

**Thesis:** A sealed letter on cream paper: wide margins, ink-blue type and a single thread of gold, saying very little and meaning all of it.

**Voice:** Quiet, exact and unhurried. Short sentences, plain words, no superlatives. The house speaks like a handwritten note: it states the two numbers, admits what is not ready yet, and invites a letter.
